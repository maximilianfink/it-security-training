# Pizza Pronto lab (code)

This folder is the running lab environment. The **instructions** (OSINT, Supply Chain, DevSecOps,
Skill Battle) are in the participant guide one level up:
[Introduction to IT Security](../README.md).

```bash
./lab.sh setup       # once, with internet (~5 GB)
./lab.sh start       # Supply Chain lab: shop :3000 · collector :8000
./lab.sh devsecops   # + Gitea + CI  :3030
./lab.sh code        # open the shop code in VS Code
./lab.sh status      # containers + URLs
./lab.sh reset       # back to start   ·   ./lab.sh stop
```
