# LAB: Web Security

## OWASP Juice Shop
The OWASP Juice Shop is an intentionally vulnerable web application for security training purposes. In this lab, you will set up and explore the Juice Shop to understand common web vulnerabilities.

Use docker-compose to set up the Juice Shop environment:
```bash
cd Web-Security/OWASP-Juice-Shop
docker-compose up -d
```
Visit `http://localhost:3000` in your web browser to access the Juice Shop application.
